# BUG-013 — Phone Number Field Missing on Registration Form

**Module:** Registration  
**Severity:** Minor  
**Priority:** Medium  
**Status:** Open  
**Reported By:** Shivam Raj   

## Description
The registration form does not include a phone number field, which is expected for a complete e-commerce registration form to enable order-related SMS notifications.

## Steps to Reproduce
1. Navigate to https://demo.nopcommerce.com/register
2. Observe all available input fields on the form

## Expected Result
Phone number field should be present on registration form.

## Actual Result
No phone number field exists on the registration form.

## Impact
Users cannot provide phone number during registration, limiting SMS order notification capability.

## Environment
- Browser: Chrome 
- OS: Windows 10
- URL: https://demo.nopcommerce.com/register

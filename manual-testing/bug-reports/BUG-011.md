# BUG-011 — Registration Accepts Password Under 8 Characters

**Module:** Registration  
**Severity:** Low  
**Priority:** High  
**Status:** Open  
**Reported By:** Shivam Raj  

## Description
Registration form accepts passwords shorter than 8 characters without showing any minimum length validation error.

## Steps to Reproduce
1. Navigate to https://demo.nopcommerce.com/register
2. Fill in valid first name, last name, email
3. Enter "Short1!" as password (only 7 characters)
4. Enter same in confirm password
5. Click Register

## Expected Result
Validation error: "Password must be at least 8 characters long."

## Actual Result
Registration succeeds with a 7 character password.

## Impact
Security vulnerability — short passwords are significantly easier to crack.

## Environment
- Browser: Chrome
- OS: Windows 10
- URL: https://demo.nopcommerce.com/register

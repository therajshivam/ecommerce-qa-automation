# BUG-010 — Registration Accepts Weak Password Without Special Character

**Module:** Registration  
**Severity:** Low  
**Priority:** High  
**Status:** Open  
**Reported By:** Shivam Raj  

## Description
Registration form accepts a password that contains no special characters, violating standard password security requirements.

## Steps to Reproduce
1. Navigate to https://demo.nopcommerce.com/register
2. Fill in valid first name, last name, email
3. Enter "WeakPassword123" as password (no special character)
4. Enter same in confirm password
5. Click Register

## Expected Result
Validation error: "Password must contain at least one special character."

## Actual Result
Registration succeeds with weak password containing no special characters.

## Impact
Security risk — users can create accounts with weak passwords vulnerable to brute force attacks.

## Environment
- Browser: Chrome
- OS: Windows 10
- URL: https://demo.nopcommerce.com/register

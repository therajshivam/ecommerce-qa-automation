# BUG-002 — Guest Checkout Allows Empty Billing Name

**Module:** Checkout  
**Severity:** Major  
**Priority:** High  
**Status:** Open  
**Reported By:** Shivam Raj  

## Description
Guest checkout process allows users to proceed with empty billing name field without any validation error.

## Steps to Reproduce
1. Add any product to cart
2. Proceed to checkout as guest
3. Leave billing name field empty
4. Click Continue

## Expected Result
Validation error should appear on billing name field.

## Actual Result
Checkout proceeds without any error on empty billing name.

## Impact
Orders can be placed with incomplete billing information causing fulfillment issues.

## Environment
- Browser: Chrome
- OS: Windows 10
- URL: https://demo.nopcommerce.com/checkout

# BUG-009 — Registration Accepts Single Character in Name Fields

**Module:** Registration  
**Severity:** Low  
**Priority:** High  
**Status:** Open  
**Reported By:** Shivam Raj  

## Description
Registration form accepts a single character as a valid first name and last name without any validation error.

## Steps to Reproduce
1. Navigate to https://demo.nopcommerce.com/register
2. Enter "S" in First Name field
3. Enter "R" in Last Name field
4. Enter valid email, password and confirm password
5. Click Register

## Expected Result
Validation error: "First name must be at least 2 characters long."

## Actual Result
Registration succeeds with single character names. Account is created successfully.

## Impact
Invalid user data stored in system. Poor data quality for business reporting.

## Environment
- Browser: Chrome
- OS: Windows 10
- URL: https://demo.nopcommerce.com/register

# BUG-007 — Quantity Accepts 0 Without Error Message

**Module:** Cart  
**Severity:** Major  
**Priority:** High  
**Status:** Open  
**Reported By:** Shivam Raj  

## Description
Cart quantity field accepts 0 as a valid value without showing any validation error when user clicks Update.

## Steps to Reproduce
1. Login and add any product to cart
2. Go to cart page
3. Change product quantity to 0
4. Click Update button
5. Observe result

## Expected Result
Validation error should appear: "Quantity must be at least 1."

## Actual Result
Cart updates with quantity 0 showing no error, product remains in cart with zero quantity.

## Impact
Incorrect order data — orders can potentially be placed with 0 quantity items causing fulfillment errors.

## Environment
- Browser: Chrome
- OS: Windows 10
- URL: https://demo.nopcommerce.com/cart

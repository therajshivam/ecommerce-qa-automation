# BUG-001 — Cart Total Not Updating Without Clicking Update

**Module:** Cart  
**Severity:** Major  
**Priority:** High  
**Status:** Open  
**Reported By:** Shivam Raj  

## Description
Cart total does not update automatically when user changes product quantity. User must manually click the Update button for the total to reflect the new quantity.

## Steps to Reproduce
1. Login with valid credentials
2. Add any product to cart
3. Go to cart page
4. Change quantity of product manually
5. Observe cart total without clicking Update

## Expected Result
Cart total should update automatically when quantity is changed.

## Actual Result
Cart total remains unchanged until user explicitly clicks the Update button.

## Impact
User may proceed to checkout with incorrect total, leading to confusion and poor user experience.

## Environment
- Browser: Chrome
- OS: Windows 10 
- URL: https://demo.nopcommerce.com/cart

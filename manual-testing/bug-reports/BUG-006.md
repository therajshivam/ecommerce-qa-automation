# BUG-006 — Change Password Accepts Same Old Password

**Module:** My Account  
**Severity:** Major  
**Priority:** High  
**Status:** Open  
**Reported By:** Shivam Raj  

## Description
Change password functionality allows users to set the same password as their current password without any warning or error.

## Steps to Reproduce
1. Login with valid credentials
2. Go to My Account
3. Click Change Password
4. Enter current password in old password field
5. Enter same password in new password field
6. Click Save

## Expected Result
Error message should appear: "New password cannot be same as old password."

## Actual Result
Password change succeeds without any error even though old and new passwords are identical.

## Impact
Security concern — users may believe their password was changed when it was not effectively updated.

## Environment
- Browser: Chrome
- OS: Windows 10
- URL: https://demo.nopcommerce.com/customer/changepassword

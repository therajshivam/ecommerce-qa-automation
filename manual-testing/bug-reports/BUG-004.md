# BUG-004 — Special Characters in Search Cause Blank Page

**Module:** Search  
**Severity:** Critical  
**Priority:** High  
**Status:** Open  
**Reported By:** Shivam Raj  

## Description
Entering special characters in the search bar causes the page to go completely blank instead of showing no results message.

## Steps to Reproduce
1. Go to homepage
2. Enter "@@##!!" in search bar
3. Click Search button
4. Observe result

## Expected Result
Page should display "No products were found that matched your criteria" message.

## Actual Result
Page goes completely blank with no content visible.

## Impact
Critical UX break — users encounter blank page with no way to recover except manually navigating back.

## Environment
- Browser: Chrome
- OS: Windows 10
- URL: https://demo.nopcommerce.com/search

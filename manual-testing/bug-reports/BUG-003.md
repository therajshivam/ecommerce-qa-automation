# BUG-003 — Password Field Briefly Unmasks on Mobile

**Module:** Auth  
**Severity:** Minor  
**Priority:** Medium  
**Status:** Open  
**Reported By:** Shivam Raj  

## Description
Password field briefly shows plain text characters for a split second when user starts typing on mobile devices.

## Steps to Reproduce
1. Open login page on mobile browser
2. Tap on password field
3. Start typing password quickly
4. Observe password field

## Expected Result
Password should remain masked at all times.

## Actual Result
Password characters briefly appear as plain text before being masked.

## Impact
Security risk if someone is observing the screen during login.

## Environment
- Browser: Chrome
- OS: Android
- URL: https://demo.nopcommerce.com/login

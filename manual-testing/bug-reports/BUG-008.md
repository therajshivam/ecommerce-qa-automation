# BUG-008 — Back Button During Checkout Loses Cart Data

**Module:** Checkout  
**Severity:** Minor  
**Priority:** Medium  
**Status:** Open  
**Reported By:** Shivam Raj  

## Description
Pressing the browser back button during the checkout process causes all cart data and entered billing information to be lost.

## Steps to Reproduce
1. Add products to cart
2. Proceed to checkout
3. Fill in billing details
4. Click browser back button
5. Navigate forward to checkout again

## Expected Result
Cart data and entered billing information should be preserved.

## Actual Result
Cart is emptied and all billing information is lost, user must start checkout process from beginning.

## Impact
Frustrating user experience — users who accidentally press back button lose all progress and must re-add items to cart.

## Environment
- Browser: Chrome
- OS: Windows 10
- URL: https://demo.nopcommerce.com/checkout
